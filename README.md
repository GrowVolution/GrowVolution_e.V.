## 🔱 Branching rules and meaning
To keep the development of our internal architecture clean, we want to provide a short introduction into our branching system:
1. main - Contains the adopted versions of our governance documents. Can only be changed by pull requests. A pull request will initiate internal the adoption process.
2. unadopted - Is the actively maintained branch which contains the current state of our documents before adoption.
3. orders/* - Contains newly created orders and their developments before they are merged into the unadopted branch.
